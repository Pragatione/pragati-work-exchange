🔥 Connect Firebase

Connect your Firebase project to enable real user accounts, live data, and full functionality. Follow these 4 steps:

Step 1 — Go to console.firebase.google.com → Create project → name it pragati-work-exchange
Step 2 — Enable Authentication → Email/Password sign-in method → Save
Step 3 — Enable Firestore Database → Create → Start in test mode → Select region
Step 4 — Project Settings → Add Web App → Copy config values below
